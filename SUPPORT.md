# Support

Use the repository's [issue forms](https://github.com/ClementG91/MCP-FlowSentinel/issues/new/choose) for reproducible bugs, feature requests, and installation questions. Search existing issues first and include the operating system, MCP client, FlowSentinel version, relevant configuration with secrets removed, and minimal reproduction steps.

For packet-capture problems, also include the output of `mcp-flowsentinel --check`. Redact IP addresses, hostnames, process arguments, PCAP contents, webhook URLs, API keys, and any other sensitive operational data before posting.

Security vulnerabilities must not be reported in public issues. Follow [SECURITY.md](SECURITY.md) and use [GitHub private vulnerability reporting](https://github.com/ClementG91/MCP-FlowSentinel/security/advisories/new).

This community project provides support on a best-effort basis and does not offer a response-time or remediation-time SLA.
